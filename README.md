loan-processor
---------------------


This repository is a small web application that will be a loan processor. Individuals can create loans, update loan details, and pay down loan balances.


# One time configuration and setup
- Initialize Openspec `openspec init --tools claude`
- Go to the Openspec custom configurations: https://github.com/intent-driven-dev/openspec-schemas
- Install the spec-driven-with-adr plugin by copying the contents of openspec/schemas/spec-driven-with-adr to openspec/schemas


# Installation
- Install Openspec `npm install -g @fission-ai/openspec@latest`
- Install Claude Code

# Usage
- open a terminal
- Go to the loan-processor directory
- open Claude code
- Use the /openspec-propose command
- Type in the expectations of your feature
- Create a PR utilizing the proposed documents
